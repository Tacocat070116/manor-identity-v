# 중앙 검색 홈

2026-10-31 검토 시안 승인 후 본 사이트 적용 요청을 반영했다.

- 첫 화면: 영어 포인트 문구, 중앙 타이틀, 검색창, 전체 캐릭터 보기.
- 검색: 기존 이름·별명·초성·영문 자판 검색, 간단한 결과 목록, 결과가 없는 경우 안내.
- 전체 도감: 기존 진영·역할·즐겨찾기 필터와 정렬 유지. 도감 내 검색은 필터와 함께 적용.
- 모바일: 입력 시 검색창을 위로 배치하고 44px 이상 버튼·16px 입력 글씨를 사용.
- Enter로 결과 확인, 아래 방향키로 첫 결과 이동, Escape로 검색어 지우기.
- 카드 회전 코드는 제거. 보조 특성 크기 변경 시안과 버전 공지는 이번 적용에서 제외.

검토 보드: `python design/home-search/build-preview.py` 실행 후 관리형 미리보기에서 `/__search-review.html`을 연다. 원본 홈 화면을 두 크기의 iframe으로 확인하며 별도의 앱 사본은 만들지 않는다.
