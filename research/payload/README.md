# 공개 데이터 용량 정리

2026-10-30에 배포된 v1.16.0을 기준으로 브라우저 코드의 필드 참조를 확인했습니다.

- `data.json`에서 캐릭터의 과거 출처·평가 메모와 상성의 중복 URL·내부 검토 메모를 분리했습니다.
- `ranked/index.json`에서 화면이 읽지 않는 반복 출처 설명, 원문 URL 목록과 빈 패치 필드를 분리했습니다.
- 모든 캐릭터·상성·조합·랭킹전 집계 항목을 유지했습니다. 맵·날짜·랭크·진영·비율·검토 필요 상태를 제거하지 않았습니다.
- 실제 이미지와 경기 기록은 참조 중이므로 유지했습니다. 중단된 통계 확장 작업본은 이번 작업 경로 밖에 보존되어 있습니다.

분리한 값은 로컬의 `retired-fields.json`에 파일·레코드 ID별로 보관합니다. 이 보관 파일은 Git 추적과 외부 업로드에서 제외합니다. 공개 사이트는 `dist/`만 배포하므로 이 조사 자료를 불러오지 않습니다. 원자료를 다시 생성한 뒤에는 `npm run release -- --refresh`를 실행합니다. 생성 단계가 복원한 미사용 필드는 다시 분리되고, 변경된 원문 값은 로컬 보관 자료에도 갱신됩니다.

정리 전후의 공략 데이터는 1,354,663 → 1,084,539바이트, 랭킹전 색인은 548,204 → 238,872바이트입니다. 합계 579,456바이트는 압축 전 JSON 크기 차이이며 실제 네트워크 전송량은 HTTP 압축과 브라우저 캐시에 따라 달라집니다.

`public-payload.test.mjs`는 기존에 공개한 v1.16.0의 Git 이력에서 분리한 값을 복원했을 때와 공개 JSON만 사용했을 때의 캐릭터·상성 화면 및 모든 랭킹전 집계 선택 화면이 동일한지 검사합니다. `scripts/public-payload-history.mjs`에 원본 공개 blob의 해시가 기록되어 있으며 로컬 보관 파일 없이 검사할 수 있습니다. CI는 전체 Git 이력을 받아 이 검증을 실행합니다. 기존 자료 검사는 경기 결과, 비율, 출처 연결, 용어 이력을 계속 확인합니다.
