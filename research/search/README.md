# 캐릭터 검색 사전

`characters.json`은 89명에 대한 검색 별칭과 글로벌 출시 순서의 근거를 보관합니다. 화면의 공식 캐릭터 이름은 `dist/data.json`을 그대로 사용합니다.

본명, 영어·일본어 직업명, 한국어 축약과 표기 변형을 검색에 연결했습니다. 별칭은 검색 편의를 위한 편집 사전이며 공식 호칭이나 이용 빈도 순위를 뜻하지 않습니다. `미치코빠칭코`는 사이트 소유자가 요청한 별칭입니다. 노튼·마이크·멜리·루키노·오르페우스·조커·에밀처럼 본명이 겹치는 인물은 여러 캐릭터에 연결하고 각 화면의 진영·중복 선택 제한을 유지합니다.

출시 순서는 글로벌 서버에서 최초로 획득할 수 있었던 시점을 기준으로 합니다. 정수나 이벤트를 통한 선행 획득을 포함하며 중국 서버, 테스트 서버, 이후 상점 판매·랭킹전 개방일은 사용하지 않습니다. 같은 날짜는 가나다순입니다. 초기 서비스 캐릭터는 글로벌 iOS 개시일인 2018-07-05로 묶었습니다. 공식 이관 공지의 날짜가 충돌하는 샤먼은 정확한 날짜를 만들지 않고 2018-08-07~09 범위를 보관합니다. 해당 범위에 다른 캐릭터 출시는 없어 순서는 결정할 수 있습니다. 캐릭터별 `sources`와 필요한 경우 `note`에 근거·예외를 남겼습니다.

사전을 수정한 뒤 저장소 루트에서 `node scripts/build-character-search.mjs`를 실행하면 공개 모듈 `dist/character-search-data.js`가 갱신됩니다. 이후 일반 릴리스 절차로 모듈 캐시 키를 갱신합니다. 검색 기능 검증은 `node --test character-search.test.mjs` 또는 `npm test`에 포함되어 있습니다.

검색은 공백·구두점·대소문자 차이를 정규화하고, 한글을 두벌식 자판 입력으로 분해해 한/영 전환 실수와 섞어 쓴 입력을 처리합니다. 두 글자 이상의 초성 검색도 지원합니다. 무관한 캐릭터를 제시하기 쉬운 무제한 편집 거리 보정은 사용하지 않습니다.
