# 2026-10-27 갱신 기록

기준 배포: `bc3011122fac5c9fd798fbe97f57dbbdd5c7c594` (BETA v1.14.0).

## 게임 공지

[10월 22일 공식 공지](https://www.identityvgame.com/en/news/announcement/20261021/35288_1317338.html)를 대조해 신동·치과의사·훌라발루·마술사·선지자·공장장의 관련 운용 문장과 치과의사/신동 상성의 적용 범위를 수정했다. 변경 전후 문장은 `patch-review.json`에 기록했다. 공략 전체 검토일과 이번 게임 공지 반영일은 분리한다. 능력 수치·난이도·상성 우위를 임의로 재평가하지 않았다. 영문 공지의 Escape 동작은 정확한 한국어 기능명이 확인되지 않아 구체적인 캐릭터나 탈출구 행동으로 단정하지 않았다.

## 대회 기록

[공개 대회 기록](https://identityv-match-log.vercel.app/)의 새 경기/기존 빈 경기 17페이지를 수집했다. 가을 IJL·IVL의 102개 라운드를 추가해 총 16,953경기, 결과 확인 16,932경기가 됐다. 원문 날짜 기준 최신 기록은 2026-10-26이다. 이 출처는 공식 중계 등을 정리한 팬 자료이며 전체 공식 원본의 전수 검증을 뜻하지 않는다.

기존 완료 경기 256페이지는 이전 스냅샷을 재사용했다. `match-log.json`에는 이번에 받은 페이지의 사실만 저장하고, 이전 원자료 경로와 SHA-256을 연결했다. 세트별 4인 구성, 캐릭터 진영, 맵, 탈출 수와 점수, 날짜 및 중복을 검사했다. 새 개인 기록의 탈출 합계는 팀 결과와 일치했다. 전체 생존자 밴 100건을 추가했고 중복/출전 구성과 겹치는 2건은 보류했다. 기존 선밴 15,516건과 이전의 결과 불일치 보류는 그대로 유지했다.

## 랭킹전

기존 보관소 2곳의 최신 커밋은 10월 21일 점검 때와 같았다. 동적 원자료 페이지의 직접 조회는 HTTP 403으로 막혀 신규 수치를 검증하지 못했다. 기존 32,667항목·421개 집계와 2026-10-17 수집일을 보존했다. 대회 최신 날짜와 랭킹전 수집일을 서로 다른 라벨로 표시한다.

## 미사용 자료 정리

현재 코드가 읽지 않는 랭킹전 CSV·ZIP·공개 manifest 1,454,564바이트를 배포 대상에서 제거했다. 빌드 스크립트도 재생성하지 않도록 바꿨으며 감사용 manifest는 `research/ranked/build-manifest.json`에 둔다. 초기 `data.json`의 사용 종료된 출처 목록·과거 수집 의견은 `retired-public-data.json`에 보존하고 공개 payload에서 제외했다. 초기 데이터는 1,623,042 → 1,310,333바이트(19.3% 감소). 살아 있는 상성·시너지·대회·랭킹 기록 및 실제 유저 게시물은 제거 대상이 아니다.

## 화면 정리

통계 요약의 숫자와 설명을 같은 기준선에 맞추고 검색·정렬 입력 높이를 48px로 통일했다. 좁은 화면의 통계 카드는 숫자 2열과 날짜 행으로 재배치했다. 공략 본문은 PC 26px·모바일 24px 줄 간격을 적용하고, 게임 반영일을 공략 검토일 옆에 정렬했다. 비교·대응 등 페이지 제목은 단어 단위로 균형 있게 줄바꿈한다. 사용 종료된 출처/다운로드 화면의 CSS를 제거했다.

재현: `python3 scripts/build-october-refresh.py` 및 `python3 scripts/build-ranked.py`. 이후 `npm run release -- --refresh`로 캐시·체크섬 갱신.
