# 한국어 용어와 문장 교정

2026-10-22, BETA v1.8.1의 캐릭터 89명 설명, 상성 근거 462개, 조합·보조 특성 설명 275개를 대상으로 문장을 검토했다. 소개, 역할 설명, 이전 이용자 의견 요약에도 같은 용어 기준을 적용했다.

한국어 공식 공지와 국내 이용자 공략에서 명칭과 실제 용례를 확인했다. 공식 원문으로 확인한 용어와 공동편집 공략에서 확인한 용어는 `terminology.json`에 구분해 기록했다. 미러는 원문과 같은 출처이며, 독립적인 검증 자료로 중복 계산하지 않았다.

사용한 편집 기준:

- 누구의 행동인지 밝히고, 조건 → 행동 → 결과가 이어지도록 쓴다.
- 번역체와 추상적인 표현을 구체적인 행동으로 바꾼다. 예: “부상을 정비” → “체력을 회복”.
- 사용법과 사용 시점을 따로 설명하고, 같은 문장을 반복하지 않는다.
- 실제 국내 용어인 평타, 후딜, 해독기, 아드는 문맥에 맞게 유지한다.
- 캐릭터별 명칭과 조사를 함께 고친다. 다른 캐릭터의 동명·유사 아이템에는 적용하지 않는다.
- 캐릭터 카드의 상성 설명은 해당 근거의 요약·조건과 동일하게 맞춘다.

기존 패치 날짜, 수치, 경기·밴 원자료, 출처 URL, 상성 방향·확신도·반영/보류 여부와 대표 상성의 순서는 유지했다. 용어를 확인한 과거 공지로 최신 게임 판정을 추정하지 않았다. 새 문장에도 기존 자료의 조건과 예외를 남겼다.

`languageReviewedAt`은 한국어 교정일이다. 기존 공략 검토일과 상성 검토일은 갱신하지 않았다. `summary.json`에는 범위와 보존된 집계를, `edits.json`에는 JSON 경로별 수정 전후를 기록했다. 수정된 문자열 수에는 화면별로 반복되는 상성 설명과 조합 문장이 포함된다.
