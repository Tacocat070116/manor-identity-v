# 기존 기능 완성도 보강 검토

- 기준 배포: `7fe755a2bc63d0e30dc3abfee6d5675963e93b1d` (BETA v1.15.7)
- 요청 범위: 이전 평가의 1·3·4·7·8번. 공개 근거·신뢰도 UI(2), 인증·자동 홍보 배지 정책(5), 홈·헤더·주 메뉴 디자인 개편(6)은 제외합니다.
- 별도 밴 분석 메뉴를 통계 안으로 옮기는 변경은 3번 범위입니다. 기존 `#v=bans` 링크는 유지합니다.

## 구현

- 비교와 즐겨찾기는 동일한 승인 상성에서 상황·요약·조건·다른 상황을 읽습니다. 상황은 접지 않고 표시하며 조건과 예외는 펼쳐 볼 수 있습니다. 모바일 비교의 상성 부분은 캐릭터별 한 열로 읽습니다.
- 밴 기록은 선택한 생존자를 모두 포함하는 실제 경기만 조회합니다. 보정점수, 추정 순위, 일치 기록이 없는 후보를 제거했습니다. 서로 다른 수집 범위는 분리하고 모든 보관 행을 유지합니다. 감시자별 원기록 조회, 20경기 단위 페이지 이동, 공유 링크를 제공합니다.
- 매치업은 대진별 상성과 적용 조건을 먼저 보여 줍니다. 공통 스킬·대응·인격은 닫힌 상세 영역으로 옮겼습니다. 기록이 없는 대진에 일반론으로 유불리를 만들지 않습니다.
- 채널 등록의 첫 화면에는 필수 3개 항목을 두고 선택 사항은 4개 묶음으로 접었습니다. 기존 소개·영상·태그·캐릭터·휘장·티어·꾸미기 값과 운영자 추천 정책을 보존합니다.
- 89명의 역할·소개·장점·사용·보존·주의를 함께 검토하고 9명의 문구를 보완했습니다. 필드별 변경과 자료 확인 수준은 `consistency-edits.json`, 캐릭터별 검토는 `../content-review.json`에 기록했습니다. 게임 밸런스 전체 재검증이나 공략 검토일 갱신이 아닙니다.
- 관련 필드 변경 시 전체 묶음 검토 기록을 요구하는 내부 검사를 추가했습니다. 이 검사는 문장의 사실성을 자동으로 판단하지 않습니다.

## 브라우저 확인

- Chrome에서 320·375·430·768·1280px 폭의 비교, 매치업, 밴 기록, 채널 등록 화면을 확인했습니다. 문서 가로 넘침이 없었습니다. 기본 밝은 테마와 다크 테마를 확인했습니다. 실제 iPhone/Safari 기기 검증은 아닙니다.
- 묘지기–사도는 구출로 표시되고 이전의 넓은 추격·구출 상세 라벨은 표시하지 않습니다. 묘지기–우산의 영혼은 추격 본문과 별도의 구출 상황을 펼쳐 읽을 수 있습니다.
- 즐겨찾기 궁수·묘지기의 공통 상대인 시공의 그림자에서 궁수는 커버, 묘지기는 추격으로 각각 표시됩니다.
- 블러디 퀸–기상학자의 승인 상성 없음 상태와 닫힌 공통 설명을 확인했습니다.
- 기존 선밴 자료에서 의사·샤먼 조합은 5경기(광기의 눈 3, 밀랍인형사 2)로 표시됩니다. 감시자 필터, 선택 해제, 페이지 이동, 자료 전환 시 페이지 초기화를 확인했습니다.
- 채널 신규 입력의 필수 항목, 선택 사항 접기·펼치기, 미리보기를 확인했습니다. 기존 채널 편집에서 소개·영상·태그 11개·캐릭터 3명·휘장 5개·티어 2개·꾸미기 값이 보존됐습니다.
- 채널 편집 검증은 로컬 fixture에서만 수행했고 쓰기 요청을 차단했습니다. 실제 공개 채널이나 운영자 데이터는 변경하지 않았습니다.

## 필수 검증

- `npm test`: 데이터 및 UI 회귀 검사와 채널 폼·정규화 검사.
- `node scripts/check-release.mjs --base <기준 배포>`: 새 공개 버전·패치노트·캐시 키 확인.
- `node scripts/check-content-consistency.mjs --base <기준 배포>`: 변경 전후 문구 묶음 검토 확인.
- `python scripts/build-korean-terminology.py --check`: 과거 용어 기록과 후속 편집 재생 확인.
- `sha256sum --check --status SHA256SUMS.txt`, `git diff --check`.

배포용 파일에는 로컬 QA fixture나 브라우저 테스트 입력을 포함하지 않습니다.
