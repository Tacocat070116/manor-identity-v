미기재는 0이나 미선택으로 바꾸지 않고, 개인 지표가 출처 간 충돌한 경우
기존 값을 유지한 한계가 있습니다. 개인 지표·인격 비율은 해당 항목이
실제로 기재된 표본을 분모로 사용합니다.

[전체 생존자 밴](../../dist/bans-observed.json)은
2020-06-25~2026-10-30의 16,842목록입니다. 한 행에 여러 캐릭터가 들어갈 수
있으므로 개별 캐릭터의 밴 횟수와 다릅니다. 두 자료는 수록 단계·기간이
다르고 같은 반경기가 겹칠 수 있어 합산하지 않습니다. 일반 대회 통계의
밴율은 선밴 기준을 유지하며, 감시자 밴율용 통합 자료는 제공하지 않습니다.

최신 추가분은 10월 30일 DOU5–ASC 2세트의 두 반경기뿐으로, 해당 날짜나
대회 전체 수집이 아닙니다. BWIKI 공급자는 COA I~III, 2018~2019년 일부 IVC,
2023·2024 일본 IVT, 2025 지역 IVT 등의 공백을 알렸습니다. 이는 공급자가
선언한 누락이며 다른 출처도 포함하는 MANOR 전체의 확정 누락 목록은
아닙니다. 개별 경기 누락도 있어 모든 대회·시즌의 완전성을 보증하지 않습니다.
[출처 점검](../refresh/2026-10-29/tournament/source-coverage.json)과
[실제 통합 결과](../refresh/2026-10-31/integration.json)를 함께 확인합니다.

## 통계 해석의 한계

중국 픽률·밴율은 같은 진영의 선택 비중이고, 아시아는 원문의 출현율·밴율을
보존합니다. 대회 픽률은 반경기당 출전 비율로 생존자 합계가 400%입니다.
대회 승·무·패는 확인된 결과만, 밴율은 별도의 선밴 목록을 분모로 사용합니다.
분모가 다른 지표를 합산하거나 직접 같은 척도로 비교하지 않습니다.

공식 통계의 커뮤니티 전사·보관본이며 현재 공식 서버의 실시간 응답이
아닙니다. 공식 원본 이미지를 모두 전수 대조한 것은 아닙니다. 일본어
사이트의 아시아 자료를 일본 이용자만의 표본으로 보지 않고, DWRG Tools·
ASGneo·idv-wubang·作业君 등 같은 원천 계열의 보관본을 독립 표본으로
더하지 않습니다. 일본어 표의 평균 행·무승부 제외 가공 승률은 사용하지
않습니다. 랭킹전 표본 경기 수·플랫폼 구분은 추정하지 않으며, 일반 집계나
팀 결과에서 조합의 인과 효과·개별 상성 승률·개인 추격 승률을 만들지 않습니다.

## 입력과 검증

`normalized-inputs.json.gz`는 확장 전 통계의 보존 입력이고
`source-manifest.json`은 그 초기 원본 목록입니다. 현재 전체 수록 수나
최신 수집일을 이 초기 파일만으로 판단하지 않습니다.
`refreshes.json`이 검토한 중국·아시아 비율과 인지 점수 추가 입력을 지정하고,
`build-manifest.json`에 적용한 입력·출처·제외·중복 처리 내역을 남깁니다.

빌더는 오류 검토 상태의 집계를 제외하고 캐릭터·진영·서버·비율 범위·
승무패 합·중복·기간을 검사합니다. 신규 압축 입력은 JSON 전체 구조와
필드를 검토한 공개 캐릭터 통계·공개 대회 기록입니다. 일반 게시글이나
인증 정보를 압축해 올리지 않습니다.

다음은 **통계 재생성이 필요한 작업**의 절차입니다. 문서만 수정할 때는
생성기를 실행하지 않고 수정 문서의 체크섬만 갱신합니다.

```sh
python3 scripts/build-ranked.py
python3 scripts/build-statistics-expansion.py
npm run release -- --refresh
npm test
node scripts/check-release.mjs --base <이전-공개-커밋>
sha256sum --check --status SHA256SUMS.txt
```

대회 생성기는 고정 기준 자료에 검토한 추가분·정정분을 재적용합니다.
새 입력을 검토하지 않은 채 최신 수집을 수행하는 명령으로 사용하지 않습니다.

랭킹 96,505행과 인지 점수 274,016행을 정규화 입력과 전수 대조한 기존
검증과, 중국·아시아의 기간·단위·지역 구분, 일본어 표의 승률 구분,
대회의 승패 관점·0과 미기재 구분에 대한 감사는
[numeric-audit.json](../refresh/2026-10-31/numeric-audit.json)에 있습니다.
이는 정규화·배포 일치 검사이며 공급자의 통계 자체 정확성을 보증하지 않습니다.
[stage-validation.json](stage-validation.json)의 테스트·브라우저 기록은
당시 검증 이력으로 보존합니다.

인지 점수는 선택한 월만 불러옵니다. 파일 일부를 불러오지 못해도 다른
통계는 유지하고 기존 다시 불러오기 동작으로 재시도할 수 있습니다.
분할 파일은 내용 해시로 캐시를 갱신합니다.
