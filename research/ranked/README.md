## 해석과 재생성

중국 픽률·밴율은 같은 진영의 선택 비중, 아시아는 원문의 비율, 대회 픽률은 반경기당 출전 비율입니다. 대회 생존자 픽률 합계는 400%입니다. 서로 다른 분모를 합치거나 팀 결과에서 개인 실력·상성의 인과 효과를 추정하지 않습니다.

랭킹전은 공식 통계의 커뮤니티 전사·보관본이고 대회 자료도 공개 전사 기록입니다. 공식 원본 이미지를 전수 대조한 자료나 실시간 공식 API 응답이 아닙니다. 같은 원천의 미러를 독립 표본으로 더하지 않습니다.

`normalized-inputs.json.gz`와 과거 날짜별 입력은 당시 이력입니다. `refreshes.json`이 현재 활성화한 비율 입력을 지정하고 `build-manifest.json`에 입력·출처·제외·중복 처리를 남깁니다. 새 수집 원문을 검토한 뒤 정규화하고 아래 명령으로 재생성합니다.

```sh
python3 scripts/build-ranked.py
python3 scripts/build-statistics-expansion.py
npm run release -- --refresh
npm test
node scripts/check-release.mjs --base <이전-공개-커밋>
node scripts/check-content-consistency.mjs --base <이전-공개-커밋>
sha256sum --check --status SHA256SUMS.txt
```

분할 파일은 내용 해시로 캐시를 갱신하며 선택한 시즌만 불러옵니다. 로딩 실패 시 다른 통계는 유지하고 다시 불러올 수 있습니다. 재생성·테스트는 입력과 공개 파일의 일치와 계산을 검사하며 원문 자체의 정확성을 보증하지 않습니다.
