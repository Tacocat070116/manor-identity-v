# MANOR · 제5인격 가이드 v1.0.0

타코캣이 직접 소유하고 운영하는 비상업적 제5인격 가이드입니다. 이 저장소에는 독립 호스팅에 필요한 전체 소스와 자료가 포함돼 있습니다.

- 소스 저장소: https://github.com/Tacocat070116/manor-identity-v
- 배포 방식: 본인 Cloudflare 계정의 Pages 무료 플랜 + 기본 `pages.dev` 주소
- 배포 상태: GitHub 소스 이전 단계. 외부 사이트 주소는 실제 배포가 완료된 뒤 기록합니다.

## 바로 시작하기

1. 이 저장소의 `main` 브랜치를 사용합니다.
2. 본인 Cloudflare 계정에서 Pages 프로젝트를 만들고 해당 저장소를 연결합니다.
3. 배포 디렉터리는 `dist`, 빌드 명령은 `npm test`, 배포 브랜치는 `main`으로 설정합니다.
4. 배포가 성공하면 발급된 무료 `pages.dev` 주소로 접속합니다. 별도 도메인 구매 없이 운영합니다. 정확한 순서는 [DEPLOY.md](DEPLOY.md)를 참고하세요.

이 사이트는 HTML, CSS, JavaScript와 JSON 파일만으로 구성됩니다. 운영 중 ChatGPT API, Google Sheets API, 외부 데이터베이스, 비밀키, 유료 AI 호출을 사용하지 않습니다. GitHub와 Cloudflare를 나중에 바꾸어도 `dist` 전체를 일반 정적 웹 호스팅으로 옮길 수 있습니다. 외부 링크는 출처를 확인할 때 사용합니다.

## 포함된 기능과 자료

- 캐릭터 89명과 정사각형 프로필 이미지 89장.
- 캐릭터 탐색·검색·즐겨찾기, 조건별 상성, 30초 대응 브리핑, 동일 진영 비교.
- 대회 기록 16,757건, 밴 기록 15,516건, 채택한 상성 근거 447건, 출처 문서 202개.
- 밴 후보 분석, 기간·맵·대회 필터, 개인 즐겨찾기 풀의 공통 약점.
- 기존 Liquid Glass 모티브 디자인, 모바일 화면 구성, 밝은 화면·어두운 화면, 동작 감소 설정 대응.

수치와 자료는 기존 2026-10-16 이관본입니다. 공략 검토일은 2026-10-14, 최신 경기일은 2026-10-05입니다. 현재 날짜의 모든 패치를 반영했다고 해석하면 안 됩니다.

## 파일 구성

| 파일 | 용도 |
| --- | --- |
| `dist/` | 실제 서비스에 배포할 파일 전체 |
| `dist/index.html` | 제목, 기본 설명, 화면 뼈대 |
| `dist/style.css` | 색상, 곡선, 반투명 재질, 반응형 화면 |
| `dist/app.js` | 화면과 사용자 동작 |
| `dist/model.js` | 상성·대회 통계·밴 분석 계산 |
| `dist/data.json` | 캐릭터, 상성, 출처, 커뮤니티 근거 |
| `dist/matches.json`, `dist/bans.json` | 경기·밴 기록 |
| `dist/assets/` | 원본 정사각형 캐릭터 프로필 |
| `validate.mjs` | 기존 데이터와 계산·화면 템플릿 검증 |
| `asset-manifest.json` | 이미지의 원본 출처와 파일 대응 |
| `DEPLOY.md` | 본인 계정으로 배포하고 도메인을 연결하는 순서 |
| `OPERATIONS.md` | 자료 수정, 백업, 복구, 유지 관리 |

## 검증

Node.js 22 이상에서 이 폴더를 열고 `npm test`를 실행합니다. 외부 패키지 설치가 필요하지 않습니다.

구문, 자료 무결성, 계산 방향, 최소 표본 기준, 필터, 밴 보정, URL 처리와 356개 캐릭터 화면 템플릿을 검사합니다. 실제 브라우저 시각 검증과 외부 호스팅 검증은 포함되지 않습니다.

## 소유 및 운영 범위

본인 계정에 저장소와 호스팅 프로젝트를 두면 수정·배포·백업·이전을 직접 관리할 수 있습니다. 기본 주소는 Cloudflare가 제공하며 별도로 구매한 도메인은 아닙니다. 캐릭터 이미지와 게임 자산의 권리가 이전되는 것은 아닙니다. 기존 출처 및 NetEase 권리 표기를 유지합니다.

기존 사이트의 ChatGPT 로그인 보호는 이 정적 배포본에 포함되지 않습니다. 외부 호스팅에 공개 배포하면 방문자가 자료 파일에 접근할 수 있습니다. 본인만 보는 용도라면 해당 호스팅의 접근 제어를 별도로 적용해야 합니다. GitHub 저장소를 비공개로 설정하는 것만으로 배포한 사이트가 비공개가 되지는 않습니다.

즐겨찾기와 화면 테마는 방문자의 브라우저에 저장됩니다. 도메인을 바꾸면 기존 주소에 저장한 설정은 자동 이전되지 않습니다. 원본 시트 수정도 사이트에 자동 반영되지 않습니다.
