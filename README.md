## 사이트 갱신하기

자료와 화면을 수정한 뒤 `npm run release`로 버전·업데이트 기록·캐시를 함께 갱신하고 `npm test`를 실행합니다. 검증한 변경을 `main`에 반영하면 `.github/workflows/pages.yml`이 다시 검증한 뒤 `dist`를 GitHub Pages에 배포합니다. 호스팅을 새로 설정하거나 옮기는 절차는 [DEPLOY.md](DEPLOY.md)를 참고하세요.

가이드 본체는 HTML, CSS, JavaScript와 JSON으로 구성되며 ChatGPT API, Google Sheets API, 유료 AI 호출을 사용하지 않습니다. 피드백 게시판은 별도 서버의 공용 D1 저장소를 사용합니다. 나중에 호스팅을 바꾸어도 `dist` 전체를 일반 정적 웹 호스팅으로 옮길 수 있으며, 게시판 서버 주소와 허용 출처는 별도로 확인합니다.

일반 공략 검토일과 상성 검토일은 구분합니다. 문장 편집 시트의 수동 변경 내용은 이번 작업으로 덮어쓰지 않았습니다. 이번 변경의 확인 범위는 자동 검증이며 실제 브라우저·모바일 시각 검증은 별도입니다.

## 캐릭터별 밸런스 이력 · 2026-10-21

캐릭터 상세의 `패치노트` 탭에서 기존 공식 최신 요약과 과거 나무위키 기록을 함께 제공합니다. 89개 캐릭터 문서의 나무모에 미러본을 확인했고 35개 문서에 패치노트 표가 있었습니다. 표의 92개 기록 묶음, 167개 변경을 편집 요약했습니다. 원문과 미러본의 갱신 시점이 다를 수 있으며, 모든 역대 패치를 복원한 목록은 아닙니다.

`research/patches/character-history-review.json`은 문서별 확인 결과·출처·항목 대응·제외 사유를 보존합니다. `node scripts/build-character-history.mjs`로 `dist/patches/characters.json`의 `history`를 다시 만듭니다. 공식 공지 수집 빌더를 다시 실행해도 이 이력을 함께 재생성합니다. 공식 최신 요약인 기존 `characters` 데이터는 그대로 유지합니다.

공식 공지를 대조한 항목은 적용일과 공식 링크를 표시하고, 나머지는 위키 기재일로 구분합니다. 월·시즌만 있는 기록과 날짜가 빈 행에 임의의 일자를 보충하지 않습니다. 날짜가 없는 이력은 별도로 모으고 카드 날짜 계산에서도 제외합니다. 명백한 수치·방향 모순은 공식 공지로 바로잡거나 보류했으며, 혼합 변경은 항목별 버프·너프·조정으로 나눴습니다. 오류 수정과 점수·업적·관전·별도 모드 항목은 표시 대상에서 제외했습니다.

## 소유 및 운영 범위

본인 GitHub 계정에서 수정·배포·백업·이전을 직접 관리할 수 있습니다. 기본 주소는 GitHub가 제공하며 별도로 구매한 도메인은 아닙니다. 캐릭터 이미지와 게임 자산의 권리가 이전되는 것은 아닙니다. 기존 출처 및 NetEase 권리 표기를 유지합니다.

사이트와 저장소는 공개 상태이며 방문자가 가이드, 자료 파일, 소스와 변경 이력에 접근할 수 있습니다. 가이드 열람에는 로그인이 필요하지 않습니다. 피드백 관리 권한은 별도 서버에서 확인합니다.

즐겨찾기와 화면 테마는 방문자의 브라우저에 저장됩니다. 도메인을 바꾸면 기존 주소에 저장한 설정은 자동 이전되지 않습니다. 원본 시트 수정도 사이트에 자동 반영되지 않습니다.

## 일반 랭킹전 통계

`#v=statistics`에서 전체·대회·랭킹전을 구분합니다. 전체 화면은 두 통계를 따로 보여주며 비율을 합산하지 않습니다. 랭킹전 자료는 서버·시즌·랭크·기간이 일치하는 공개 집계 하나를 선택합니다. 중국의 일별/주별/누적 값은 서로 겹치는 관측일 수 있으므로 합산하거나 평균하지 않습니다.

중국 픽률과 밴율은 같은 진영의 선택 비중입니다. 대회 픽률은 경기당 출전 비율(생존자 합계 400%)이며 밴율은 별도 생존자 선밴 자료 기준입니다. 랭킹전 표본 경기 수나 PC·모바일 분리 정보를 추정하지 않습니다. 중국 S44 자료는 정정 여부 확인이 필요해 기본 선택에서 제외하고 직접 선택 시 상태를 표시합니다.

아시아 S43 생존자·북미/유럽·한국 유저 전용·맵/인격별 원자료는 확보하지 못했습니다. 미확보·누락 캐릭터는 0%로 채우지 않습니다. 일반 랭크 집계만으로 조합별 상성 승률을 생성하지 않습니다. 공식 통계의 전사·보관본이며 현재 공식 서버의 실시간 응답이 아닙니다.

`python scripts/build-ranked.py`로 보존된 정규화 입력에서 파일을 재생성합니다. 이후 `npm test`와 배포 파일 체크섬을 갱신해야 합니다. Google 문장 편집 시트와 공략 본문은 이번 통계 수집에서 수정하지 않았습니다.

## 피드백 게시판 · 2026-10-17

메인 `근거` 메뉴는 `피드백`으로 교체했습니다. 기존 자료와 평가 기준은 하단 링크와 캐릭터 근거 화면에서 계속 열 수 있습니다.

- 글 작성, 추천·비추천 변경/취소, 댓글·답글, 최신/추천/댓글순, 분류·상태 필터, 검색과 공유.
- 닉네임은 캐릭터명과 번호로 배정하며 같은 글 안에서는 유지합니다. 글/댓글 내용은 공용 D1 저장소에 보관하고 브라우저에는 익명 참여 토큰만 저장합니다.
- 서버: https://manor-feedback.just-bean-5735.chatgpt.site · 관리: 같은 주소의 `/admin`. 서버 소스와 배포는 별도 Sites 저장소에서 관리합니다.

- 삭제·숨김, 요청 길이 제한, 기초적인 도배 제한, 동시 투표 및 중복 등록 방지, 변경 이력을 구현했습니다. 익명 참여는 기기 변경·브라우저 초기화까지 차단하는 1인 1표 방식이 아닙니다.
- 새 화면 검증은 `feedback.test.mjs`, 서버 권한·데이터 검증은 서버 저장소의 `feedback-api.test.mjs`에서 수행합니다. 실제 모바일/브라우저 조작은 별도 확인이 필요합니다.

상성·시너지·즐겨찾기 공통 상대 카드는 `characterHeading()`으로 64px 사진, 이름, 역할 태그를 동일하게 표시합니다. 상성의 기존 설명·활용 조건·근거 링크는 그대로 유지합니다. 카드 여백(데스크톱 24px, 모바일 20px), 간격, 모서리, 44px 조작 높이, 본문·캡션·태그 행간(24/20/16px)은 `style.css`의 공통 변수를 따릅니다. 화이트 모드의 배경·카드·입력란·선택 상태 경계를 강화하고 피드백에도 같은 체계를 적용했습니다. 각 모드의 본문·보조 문구·역할 태그·피드백 상태 글자색은 해당 배경과 4.5:1 이상 대비를 확인했습니다. 실제 기기에서의 시각 검증은 별도입니다.

## 게임 패치노트 · 2026-10-19

`#v=gamepatches`에서 공식 글로벌 패치 기록을 캐릭터·연도·변경 유형·검색어로 찾습니다. 마지막 플레이 날짜 이후 필터는 해당 날짜 다음 날부터 적용일이 확인된 기록만 보여줍니다. 날짜가 불확실한 공지는 공지 표기일로 정렬하고 상태를 표시합니다. 테스트 서버 공지는 별도 필터이며 캐릭터 최근 변경에는 쓰지 않습니다.

캐릭터 상세의 패치노트 탭은 검토한 버프·너프·조정 기록을 날짜별로 보여줍니다. 오류 수정은 캐릭터 패치노트에서 제외하며, 전체 공식 패치 아카이브에서는 계속 확인할 수 있습니다. 도감 카드에는 패치 날짜를 표시하지 않습니다. 스킨, 별도 모드 한정 변경, 다음 주 예고를 현재 성능 변경으로 취급하지 않습니다. 전체 기록에는 관련 콘텐츠 언급도 연결하되 캐릭터와 유형 필터를 함께 선택하면 같은 캐릭터에 해당하는 유형을 검사합니다.

- `dist/patches/archive.json`: 적용일별 기록, 변경 분야, 캐릭터 연결, 한국어 요약, 원문 링크. 화면 진입 시 한 번만 불러옵니다.
- `dist/patches/characters.json`: 초기 화면용 최근 변경 요약. 공략 검토일과 독립적으로 표시합니다.
- `research/patches/`: 별칭, 날짜 예외, 출처·해시 목록, 최근 변경 편집 근거. 원문 전문은 배포하지 않습니다.
- 수집: Python 3 + lxml에서 `python scripts/collect-game-patches.py --cache /absolute/external/cache`. 원문 HTML은 저장소 밖 캐시에 보관합니다.
- 재생성: `python scripts/build-game-patches.py --cache /absolute/external/cache`. 검토한 날짜 예외와 최근 변경 요약을 함께 읽습니다. 수집 페이지 범위와 확인일은 이번 조사 기준이며 새 공지를 자동 검증·배포하는 작업이 아닙니다.
- 출시 초기·삭제된 공지의 완전 복원은 보장하지 않습니다. 수집 범위·연도별 확보 건수와 날짜 충돌을 공개 화면에서 확인할 수 있습니다.

연습실 메뉴·화면·문제 데이터·전용 코드와 테스트를 제거했습니다. 과거 공개 업데이트 기록은 보존하며 기존 연습실 주소는 도감으로 돌아갑니다.

검증은 기존 기능 회귀 검사와 `game-patches.test.mjs`의 출처 대조, 날짜·서버 분리, 캐릭터/유형 교차 필터, 복귀 날짜, 페이지 이동, 입력 이스케이프, 지연 로딩 및 화면 해제 검사를 사용합니다. 이번 환경에서 실제 브라우저의 시각·터치 검증은 수행하지 못했습니다.

## 도감 카드와 역할 아이콘 · 2026-10-21

도감 카드의 패치 날짜·구분선과 전용 렌더링/스타일을 제거했습니다. 사진은 카드 상단에 고정하고 이름 영역은 실제 줄 수에 맞추며, 이름과 태그 사이를 4px로 유지합니다. 진영·난이도는 같은 행의 카드 하단에 정렬합니다.

`dist/specialties.json`의 89명에 대한 기존 설명·분류 근거를 확인했습니다. `specialties[0]`은 메인, 두 번째 항목은 서브라는 기존 우선순위를 유지하고 공통 렌더러에서 명시적으로 구분합니다. 태그 종류의 고정 순서로 재정렬하지 않으며, 메인만 있는 캐릭터에 서브를 만들지 않습니다. 메인·서브는 같은 글자색·두께·배경으로 표시하며 순서로만 구분합니다. 상세·비교·상성에서도 같은 순서를 사용합니다. 스크린 리더에도 메인·서브를 전달합니다.

사진 위 아이콘은 메인 태그에 대응합니다. 어그로는 신발과 속도선, 커버는 동료를 감싼 방패, 구출은 도움을 건네는 손, 운영은 연결된 지점, 해독은 암호기, 사냥은 조준점, 캠핑은 의자입니다. 7종 모두 24×24 SVG 좌표계로 제작했으며, 카드에서는 24px 배지 안에 16px 아이콘을 중앙 배치합니다. 테마 공통 색상 변수를 사용합니다.

## UI 정렬 다듬기 · 2026-10-21

장점·주의할 점은 24px 번호 열과 유연한 본문 열을 사용하고 첫 줄의 글자 기준선을 공유합니다. 번호의 별도 위쪽 여백을 없애고 자릿수 폭을 고정했습니다. 같은 컴포넌트를 사용하는 비교 화면도 함께 적용하며, 좁은 비교 카드에서는 번호 열과 간격을 줄입니다.

패널 제목은 28px(모바일 24px) 줄높이에서 아이콘을 첫 줄 가운데에 맞춥니다. 여러 줄 안내문의 아이콘과 본문을 분리해 둘째 줄부터도 본문 시작점이 유지되도록 했습니다. 역할 안내 아이콘은 상단 정렬하며, 피드백의 숫자·배지 줄높이와 모바일 업데이트 필터의 라벨 정렬도 맞췄습니다.

## 카드 이름 간격과 아이콘 복원 · 2026-10-21

카드 이름에 강제하던 두 줄 높이를 제거해 한 줄 이름 아래의 빈 줄을 없앴습니다. 긴 이름은 자연스럽게 줄바꿈하며 태그는 마지막 줄 아래 4px에 이어집니다. 최종 아이콘은 사냥·운영만 v1.5.1 형태로 복원하고 구출은 도움의 손, 캠핑은 의자 모양을 유지합니다. 어그로는 달리는 사람에서 신발과 속도선으로 바꿨습니다.

## 유저 상대법 · BETA v1.10.0

캐릭터 상세의 `유저 상대법` 탭과 상대 대응의 선택 대진에서 플레이어 상대법을 제출하고 열람합니다. 글로벌 아시아·NA/EU 서버를 지원합니다. `dist/matchup-tips.js`는 기존 피드백 서버의 `/api/tips`를 사용합니다. 공개 목록은 운영자가 승인한 글만 표시하며, 티어·시즌·확인일은 운영자의 수동 검토 기준입니다.

서버·UID·검토 참고사항은 서버의 별도 테이블에 보관하며 공개·작성자 API에 반환하지 않습니다. 이 브라우저의 익명 작성 토큰으로 내 제출 내역 확인·수정·삭제가 가능하고, 수정하면 재검토 대기로 전환됩니다. 삭제하면 비공개 검토정보도 삭제됩니다. 토큰은 기존 피드백과 공유하며 검토정보를 localStorage나 URL에 저장하지 않습니다.

운영자는 기존 [관리 화면](https://manor-feedback.just-bean-5735.chatgpt.site/admin)의 ‘유저 상대법 검토’에서 티어·작성자 본인·내용을 각각 확인합니다. UID만으로 자동 티어 인증을 하지 않습니다. 검토 근거가 부족하면 보완 요청을 남기고 작성자가 비공개 참고사항을 수정해 다시 제출하도록 안내합니다.
