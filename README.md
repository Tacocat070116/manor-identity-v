# MANOR · 제5인격 가이드 v1.0.0

타코캣이 직접 소유하고 운영하는 비상업적 제5인격 가이드입니다. 이 저장소에는 독립 호스팅에 필요한 전체 소스와 자료가 포함돼 있습니다.

- 소스 저장소: https://github.com/Tacocat070116/manor-identity-v
- 배포 방식: 본인 GitHub 공개 저장소 + GitHub Pages의 무료 기본 주소
- 운영 주소: https://tacocat070116.github.io/manor-identity-v/
- 배포 상태: 2026-10-16 GitHub Pages 공개 배포 완료. 본인 저장소의 main 변경을 검증한 뒤 자동 배포합니다.

## 바로 시작하기

1. 저장소 소유자가 공개 범위를 확인한 뒤 저장소를 공개로 전환합니다. GitHub Free의 Pages는 공개 저장소가 필요합니다.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다.
3. 준비된 배포 변경을 `main`에 반영합니다. `.github/workflows/pages.yml`이 검증 후 `dist`만 사이트에 배포합니다.
4. 배포 성공 화면에 표시되는 무료 사이트 주소로 접속합니다. 별도 도메인 구매 없이 운영합니다. 정확한 순서는 [DEPLOY.md](DEPLOY.md)를 참고하세요.

이 사이트는 HTML, CSS, JavaScript와 JSON 파일만으로 구성됩니다. 운영 중 ChatGPT API, Google Sheets API, 외부 데이터베이스, 비밀키, 유료 AI 호출을 사용하지 않습니다. 나중에 호스팅을 바꾸어도 `dist` 전체를 일반 정적 웹 호스팅으로 옮길 수 있습니다. 외부 링크는 출처를 확인할 때 사용합니다.

## 포함된 기능과 자료

- 캐릭터 89명과 정사각형 프로필 이미지 89장.
- 캐릭터 탐색·검색·즐겨찾기, 조건별 상성, 30초 대응 브리핑, 동일 진영 비교.
- 대회 기록 16,757건, 밴 기록 15,516건, 채택한 상성 근거 447건, 출처 문서 202개.
- 밴 후보 분석, 기간·맵·대회 필터, 개인 즐겨찾기 풀의 공통 약점.
- 기존 Liquid Glass 모티브 디자인, 모바일 화면 구성, 밝은 화면·어두운 화면, 동작 감소 설정 대응.

수치와 자료는 기존 2026-10-16 이관본입니다. 공략 검토일은 2026-10-14, 최신 경기일은 2026-10-05입니다. 현재 날짜의 모든 패치를 반영했다고 해석하면 안 됩니다.

## 검증

Node.js 22 이상에서 이 폴더를 열고 `npm test`를 실행합니다. 외부 패키지 설치가 필요하지 않습니다.

구문, 자료 무결성, 계산 방향, 최소 표본 기준, 필터, 밴 보정, URL 처리와 356개 캐릭터 화면 템플릿을 검사합니다. 이 명령 자체에 브라우저 시각 검증은 포함되지 않습니다. 별도로 실제 GitHub Pages 주소에서 데스크톱 첫 화면, 검색, 캐릭터 상세·상성, 새로고침 후 상세 링크 복원, 매치업, 비교·통계 필터, 밴 후보 계산을 확인했습니다. 실제 모바일 기기 검증은 별도로 필요합니다.

## 소유 및 운영 범위

본인 GitHub 계정에서 수정·배포·백업·이전을 직접 관리할 수 있습니다. 기본 주소는 GitHub가 제공하며 별도로 구매한 도메인은 아닙니다. 캐릭터 이미지와 게임 자산의 권리가 이전되는 것은 아닙니다. 기존 출처 및 NetEase 권리 표기를 유지합니다.

기존 사이트의 ChatGPT 로그인 보호는 이 정적 배포본에 포함되지 않습니다. GitHub Pages로 공개 배포하면 방문자가 사이트와 자료 파일에 접근할 수 있습니다. 저장소를 공개로 전환하면 소스 코드·JSON 자료·이미지·변경 이력도 공개됩니다. 공개 전환은 저장소 소유자의 확인 후 진행합니다.

즐겨찾기와 화면 테마는 방문자의 브라우저에 저장됩니다. 도메인을 바꾸면 기존 주소에 저장한 설정은 자동 이전되지 않습니다. 원본 시트 수정도 사이트에 자동 반영되지 않습니다.
