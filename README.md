## 사이트 갱신하기

자료와 화면을 수정한 뒤 `npm run release -- --refresh`로 캐시·검증 해시를 갱신하고 `npm test`를 실행합니다. 공지 대기 변경은 `operations/pending-changes.json`에 기록하고, 명시적인 공지 요청이 있을 때만 `--announce`로 버전과 업데이트 기록을 갱신합니다. 검증한 변경을 `main`에 반영하면 `.github/workflows/pages.yml`이 다시 검증한 뒤 `dist`를 GitHub Pages에 배포합니다. 호스팅을 새로 설정하거나 옮기는 절차는 [DEPLOY.md](DEPLOY.md)를 참고하세요.

문서만 수정할 때는 통계 생성기나 공개 파일 갱신을 실행하지 않고, 수정한 문서의 `SHA256SUMS.txt` 항목만 갱신합니다. 문서 수정일을 자료 수집일로 바꾸지 않습니다.

가이드 본체는 HTML, CSS, JavaScript와 JSON으로 구성되며 ChatGPT API, Google Sheets API, 유료 AI 호출을 사용하지 않습니다. 피드백 게시판은 별도 서버의 공용 D1 저장소를 사용합니다. 나중에 호스팅을 바꾸어도 `dist` 전체를 일반 정적 웹 호스팅으로 옮길 수 있으며, 게시판 서버 주소와 허용 출처는 별도로 확인합니다.

이 절은 당시 작업 기록입니다. 현재 반영·보류 수와 표시 범위는 위의 2026-11-13 확인 내용을 따릅니다.

일반 공략 검토일과 상성 검토일은 구분합니다. 문장 편집 시트의 수동 변경 내용은 이번 작업으로 덮어쓰지 않았습니다. 이번 변경의 확인 범위는 자동 검증이며 실제 브라우저·모바일 시각 검증은 별도입니다.

## 소유 및 운영 범위

본인 GitHub 계정에서 수정·배포·백업·이전을 직접 관리할 수 있습니다. 기본 주소는 GitHub가 제공하며 별도로 구매한 도메인은 아닙니다. 캐릭터 이미지와 게임 자산의 권리가 이전되는 것은 아닙니다. 기존 출처 및 NetEase 권리 표기를 유지합니다.

사이트와 저장소는 공개 상태이며 방문자가 가이드, 자료 파일, 소스와 변경 이력에 접근할 수 있습니다. 가이드 열람에는 로그인이 필요하지 않습니다. 피드백 관리 권한은 별도 서버에서 확인합니다.

즐겨찾기와 화면 테마는 방문자의 브라우저에 저장하며, Google 로그인 시 같은 계정의 다른 기기와 동기화합니다. 로그인하지 않은 브라우저의 설정은 도메인을 바꾸면 자동 이전되지 않습니다. 원본 시트 수정도 사이트에 자동 반영되지 않습니다.

## 일반 랭킹전 통계 · 2026-11-13 확인 기준

`#v=statistics`에서 전체·대회·랭킹전을 구분합니다. 전체 화면은 두 통계를 따로 보여주며 비율을 합산하지 않습니다. 랭킹전 자료는 서버·시즌·랭크·기간이 일치하는 공개 집계 하나를 선택합니다. 중국의 일별/주별/누적 값은 서로 겹치는 관측일 수 있으므로 합산하거나 평균하지 않습니다.

기준은 [배포 인덱스](dist/ranked/index.json)의 `meta`와 `datasets`입니다. 1행은 한 자료 묶음 안의 캐릭터별 비율이고, 1묶음은 서버·시즌·랭크·기간으로 구분한 공개 집계입니다. 1,325개는 출처 사이트 수나 파일 수가 아닙니다.

| 서버 | 비율 행 | 자료 묶음 | 수록 시즌·범위 |
| --- | ---: | ---: | --- |
| 중국 | 108,054 | 1,310 | S24·S26·S28·S32~S45. S44는 일별·주별만 수록 |

## 사용자 카드 스튜디오 · BETA v1.13.0

모바일 도감 카드의 이름·역할 태그·진영/난이도 간격을 PC와 같은 6px로 맞췄습니다. 모바일 글자 크기보다 크던 고정 줄 높이를 없애 실제 내용에 맞게 카드 높이가 줄어듭니다. PC 스타일은 유지합니다.

운영자가 미리 등록했던 모든 채널을 게시판에서 내리고 자동 등록을 중단했습니다. 기존 채널 주소도 다시 등록할 수 있게 비웁니다. 사용자 작성 채널은 유지하며 조사 자료와 검토 이력은 서버 내부에만 남깁니다. 빈 게시판에서 누구나 자신의 채널을 등록할 수 있습니다.

외부 CSS·임의 이미지 주소를 저장하지 않고 서버에서 허용된 꾸미기 값과 캐릭터를 검증합니다. 공유 모델·UI·CSS는 공용 서버와 동기화합니다. 기존 글과 구버전 클라이언트의 수정은 호환되며 권한·신고·비공개 UID 정책은 그대로 유지합니다.
